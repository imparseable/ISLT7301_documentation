# Contribution Guides
Contribution guides are included for the types of documentation in each of the [/explanations/](https://github.com/imparseable/ISLT7301_documentation/tree/Fall2026/explanations), [/how-to_guides/](https://github.com/imparseable/ISLT7301_documentation/tree/Fall2026/how-to-guides), [/reference/](https://github.com/imparseable/ISLT7301_documentation/tree/Fall2026/reference), and [/tutorials](https://github.com/imparseable/ISLT7301_documentation/tree/Fall2026/tutorials) directories. Screenshots and other reference images should be uploaded to [/images/](https://github.com/imparseable/ISLT7301_documentation/tree/Fall2026/images) and included inline with [alt-text](https://www.accessibilitychecker.org/guides/alt-text/).

Please also refer to:
- [The Markdown Guide](https://www.markdownguide.org/)
- [Diátexis: A systematic approach to documentation authoring](https://diataxis.fr/)
- [Write the Docs](https://www.writethedocs.org/guide/index.html)
