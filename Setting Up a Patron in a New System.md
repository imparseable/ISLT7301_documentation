# Tutorial to Create Patron Profiles on a Brand New Koha Account

*Note, you will need to have completed the installation and webpage setup of Koha before beginning.*

We will begin by logging into our superlibrarian Koha account. Your webpage should look like this:

Once we are logged in, our home page should look like this:

## Creating Patron Categories
With this being a brand new instance, we will need to set up patron categories before adding patron profiles. You already did this for yourself as a staff member during your Koha installation.

We will click on Koha Administration (see previous image), the select 'Patron categories' under the heading 'Patrons and circulation.' You should see your staff category and the code you assigned it. 
<img width="1290" height="687" alt="Koha Admin Page" src="https://github.com/user-attachments/assets/e63e8072-8375-4515-84ad-d2dddb1d5f7d" />
<img width="1599" height="367" alt="Patron Categories" src="https://github.com/user-attachments/assets/a63c61e7-7264-4b23-9bc3-24d705de36be" />

At the top of this page we will select 'New category.' For our practice purposes, we will only fill out the fields in red that are required. The first category we will create will be for an adult patron.

Category Code = ADULT, Description: For library adult patrons, 12 month enrollment, Category Type: Adult. 

<img width="661" height="582" alt="Adding Patron Categories" src="https://github.com/user-attachments/assets/a41be768-c469-4494-86ad-9aed4cfd8fa7" />


Now we save. The new category should be in our patron categories!
<img width="1587" height="366" alt="Adult Patron Category" src="https://github.com/user-attachments/assets/2e5cf901-7d4d-401b-a5e6-09a949b282ef" />

We can return to the home page by clicking the green house in the top lefthand corner. 

## Creating Patron Profiles
Now we can select Patrons from our home page. 
<img width="1916" height="518" alt="Patrons Home Page" src="https://github.com/user-attachments/assets/1f89da1a-fed4-4d57-9846-bbabacae7798" />

In this window we will select 'New patron,' which will open a drop down menu. We want to create a profile for the category we just made (library adult patrons). 
<img width="1092" height="534" alt="New Adult Patron" src="https://github.com/user-attachments/assets/3653e5f5-774e-4298-9563-71be83fe5080" />

Again, for practice purposes, we will only fill in basic information. But for a real patron you would need to be more thorough with addresses, contact information, restrictions (if needed), etc. For now, we will fill in the name, DOB, and required Library management information. 

<img width="666" height="507" alt="Adult Patron 1" src="https://github.com/user-attachments/assets/dbea7f61-9941-4f62-bf67-f8c965b46791" />
<img width="515" height="296" alt="Adult Patron 2" src="https://github.com/user-attachments/assets/ab21c852-94e4-424a-b94b-133dfce09bb0" />

We can now save our new patron! Do not fret when the page returns blank. Click on O for Oliver and their profile will pop up!
<img width="1904" height="537" alt="Patron Profile" src="https://github.com/user-attachments/assets/82bd53e1-ddf6-42e7-aa52-8835ac7afeeb" />

Congrats! We have successfully added a new patron category and profile. Feel free to repeat the process to create a youth category and more profiles!
