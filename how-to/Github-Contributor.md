## How to become a contributor in Dr. Ridenour's 7301 Fall 2026 GitHub Repository

This guide shows you how to become a contributor: accept the invite, then add your name to an issue in `issue.md` on the **fall 2026** branch.

## Before you start
You need a GitHub account and the invitation email from Dr. Ridenour for the repository.

## Steps
1. **Accept the invite.** Open the invitation email sent to the address linked to your GitHub account, and click to accept.
2. **Switch branches.** On the repository page, open the branch drop-down at the top left (it says **main**) and choose **fall 2026**.
3. **Open** `**issue.md**`. Click the file in the file list and choose the issue you want to fix.
4. **Click Edit.** Use the pencil icon at the top right of the file.
5. **Add your name.** Type your name between the two `|` lines next to the issue you picked (see the example below).
6. **Save.** Click **Commit changes.**

## Example

This is only an example of how a name looks. Use your own name.

`| Maria Friedman |`

## Tips

• Make sure the branch name at the top left says **fall 2026** before you edit. Edits made on **main** will not go to the right place.

• Type only your name inside the lines. Leave the `|` characters and everyone else's names as they are.
