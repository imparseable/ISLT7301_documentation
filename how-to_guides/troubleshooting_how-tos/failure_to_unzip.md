<h2>Here's what I did to fix this issue:</h2>

<p>It is essential that when you are following directions while coding, you don't miss a step. However, if this happens, it should be a relatively easy fix. This was the case when I tried to unzip a file in the example below.</p>

<p><b>It is highly recommended that you use a website like Stack Overflow or Reddit to get information from others when troubleshooting. <p> As you can see from the example, when trying to unzip and install a .zip file, the command was not being registered. <b>I did not have the unzip command utility installed.</b></p>

<p> To fix this issue, you can follow the steps below.</p>
<ol>
  <li>Install the unzip command utility by typing "sudo apt install unzip" in your command line.</li>
  <img width="645" height="141" alt="issue screenshot 2" src="https://github.com/user-attachments/assets/622d9f0a-6fe9-42e8-9683-d29547cfddc3" />

<li> Run the unzip command utility to unzip your zipped file and install it</li>

</ol>

<p>Now that you have the unzip command properly installed in your VM, you should be able to unzip any files needed in the future by using the command <b> sudo unzip filename.zip.</b></p>

<p>Again, it is important that you don't miss a step when you are trying to follow along with directions. You won't be able to unzip a file until you install the command to do so. There is an easy fix, which involves troubleshooting, double checking your work, and making sure you are following steps or advice while you are working. If you find yourself not being able to unzip something, try installing (or re-installing) this command again, as this should be the first step taken in trying to fix this issue.</p>
